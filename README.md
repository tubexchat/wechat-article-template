# 微信公众号 Markdown 排版与语法高亮工具 (WeChat Article Markdown Template Editor)

这是一个专为微信公众号排版设计的 Markdown 编辑器。它解决了微信公众号后台不支持 Markdown 直接渲染，以及直接粘贴代码块时**语法高亮丢失**的顽疾。

## ✨ 功能特点

1. **🎨 自动内联高亮 (CSS-to-Inline)**: 
   微信公众号编辑器会过滤掉非内联的 CSS 样式。本工具在点击“一键复制”时，自动将 `Highlight.js` 的所有 Token 类名（如 `.hljs-keyword`、`.hljs-string` 等）转化为相应的行内样式属性，保证在微信后台粘贴后语法高亮完美呈现。
2. **📱 微信专属排版样式 (375px 手机预览)**:
   内置极客蓝、森林绿、活力橙等多种排版主题，配置行高、段落字间距，符合公众号排版规范。提供 375px 手机端容器框，所见即所得。
3. **💻 Mac 风格代码窗口**:
   自动在代码块顶部生成带有 Mac 经典红黄绿三色控制按钮的装饰头，提升文章科技感与视觉品质。
4. **⚡ 轻量纯前端实现**:
   无需后端复杂依赖。在离线环境下也可通过外部引用的 CDN 库渲染和高亮（当您使用连接互联网的浏览器打开时）。

## 🚀 启动与使用

### 1. 运行本地开发服务器
工具内置了一个超轻量的 Node.js 静态文件服务器。使用以下命令启动：

```bash
npm start
# 或者直接使用 node 运行：
node server.js
```

启动后在浏览器中访问：[http://localhost:3000](http://localhost:3000)

### 2. 使用步骤
1. 在左侧 **Markdown 编辑器**中输入或粘贴您的 Markdown 文本（支持 ` ```py `、` ```javascript ` 等代码块）。
2. 在左侧的**排版配置**面板中，选择您喜欢的主题色、代码高亮风格（如 Atom One Dark、Dracula 等）和字号大小。
3. 在右侧 **手机预览** 中即时查看公众号文章的呈现效果。
4. 点击右上角 **“一键复制公众号格式”** 按钮。
5. 打开您的微信公众号后台编辑器，直接 `Ctrl+V` (或 `Cmd+V`) 粘贴，即可带样式与完美代码语法高亮发布！
